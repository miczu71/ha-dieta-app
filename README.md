# Dieta (add-on Home Assistant)

Planer posiłków wielodniowych: gotujesz raz, jesz kilka dni. Cele kcal i makro dla dwóch osób,
docelowo propozycje dań ze składników, które kupujecie (połączenie z add-onem Zakupy).

Instalacja: dodaj to repozytorium w Sklepie add-onów HA. Status: wczesny rozwój (E1), bez wydania.
Wartości kcal są szacunkowe, to nie porada medyczna.
